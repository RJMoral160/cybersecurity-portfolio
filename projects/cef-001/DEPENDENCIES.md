# Dependencies

- Python 3.9 or newer (the source uses built-in generic type annotations).
- Standard library only: `argparse`, `collections`, `html`, `json`, `pathlib`, `typing`, `urllib.parse`, and `unittest`. CLI tests also use `subprocess` and `tempfile`.
- No package installation, external service, API token, or network access is needed.

Run from `projects/cef-001` so the documented relative fixture paths resolve.
